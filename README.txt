【起動】
コトバクエスト.htmlをChromeなどで開いてください。
ZIP版は展開し、kotoba-quest/index.htmlを開きます。
画像・マップ・問題・効果音処理はHTMLに同梱。外部通信・CDNは不要です。
追加素材の別ダウンロードも不要です。

【動くオープニング：2026年10月8日追加】
起動すると約54秒のリアルタイム演出が始まり、その後、既存のタイトルへ移ります。
Space／Esc／画面タップで、開始直後からいつでも即スキップできます。
村の多層移動、歩く人物、文字の崩壊、ムオンの影、主人公、戦闘、仲間、
時計台・城・塔、光が集まるタイトルを、既存画像とCanvasで描画します。
動画・外部通信・CDNは使用せず、音なしで内容が分かります。
以前の「はじめから」の途中にあった文章だけの導入は重ねて再生しません。
演出中はセーブに書き込みません。終了時に演出の描画・操作受付を破棄します。
パーティクルは最大40個、演出の描画は最大30fps。動きを減らす端末設定にも対応。
本編のマップ・戦闘・問題・装備・NPC・セーブデータは変更していません。

【操作・設定】
矢印：移動　Space：話す・調べる・決定　Esc：メニュー・戻る。
Enterは使いません。画面のボタンでも操作できます。
ふりがなは右上、難易度はMENUのせっていで切り替えます。
やさしい／ふつう／むずかしい／激ムズ（小学5年～中学1年程度）。
問題・解答には、答えの手がかりになるルビを付けません。
半透明ミニマップは目的地・敵・宝箱・自位置を表示します。

【第4章への進み方】
第3章CLEAR画面で「第4章へ」を選びます。
町を歩いている場合は、北門の番人に話しかけると開始できます。
リベルタの異変→北門の番人→忘れられた街道へ。
西の廃屋で写真を調べ、橋の看板で道を直し、野営地で話を聞きます。
野営地では無料休憩・道具購入・第4章の装備購入ができます。
街道の北東からコトバ城へ入ります。
城の第一区画：うそと本当／第二区画：だれに伝える？／
第三区画：どう伝える？では、それぞれ三つの仕組みを直します。
第四区画では三つの記録を直し、北の部屋でレンと父親に会います。
最深部の光で回復し、ココロクライ（HP500）に挑戦します。
最終選択は4つとも不正解にならず、セーブに残ります。
第4章CLEAR後は「最終章へ」で、本編の結末まで進めます。

【最終章への進み方】
第4章CLEAR画面で「最終章へ」を選びます。
街道を探索している場合は、野営地のレンに話しかけると開始できます。
第4章で選んだ考えを保持し、導入会話に反映します。
野営地のレン→終わりの道→北東のことばの塔へ。
道の行商人では装備・回復アイテム購入・無料休憩ができます。
塔の第一～第四層は「読む／書く／つなぐ／伝える」。
各層の三つの試練を解くと、次の層へ進めます。
第五層では三つの言葉の記憶を調べ、その後、北の記録を読みます。
最上階では光で回復してから、ムオンへ自分の答えを伝えます。
忘却王ムオンはHP780。四つの力が消え、仲間たちの声で戻る演出があります。
最後は複合問題に正解して「ことばが届いた！」の一撃で撃破します。
思想についての選択肢に正解・不正解はありません。

【操作できるエピローグ／CLEAR DATA】
撃破後はシオンとの会話、塔の脱出、世界復活を経て、リベルタで操作に戻ります。
パン屋の店主／公園の親子／薬を届けた老人／中央広場のユウ／入口のミナ、
研究所跡のシオン／最初の村の老婆／村長を訪ねてください。
目的表示とミニマップが、次に訪ねる人を示します。
町の北門、またはMENU「仲間と移動する」から、町・村・研究所跡へ移動できます。
最後に村のレンとミナへ話すと、最後の問い→タイトル回収→THE END。
CLEAR DATAは自動保存され、「つづきから」で村から自由に再開できます。
主要人物のクリア後会話を再び読めます。ラスボスは復活しません。
MENU「冒険の記録」は既存のレベル・G・装備・プレイ時間などを表示します。
敵数は現在の撃破記録です。再出現する敵の累計討伐数ではありません。
